## Admin routes

`getAdminRoutePolicy()` phân loại 55 admin route definitions như sau.

## Coverage matrix

| Module surface | Server path chính | Persistence | Supporting tests | Canonical docs |
| --- | --- | --- | --- | --- |
| Căn hộ/cư dân | Mutate, memberships, reconciliation | Apartments, Residents, memberships | Resident membership và apartment summary tests | `/operations/apartments-residents` |
| Tương tác | Mutate, resident workflow, downloads | Feedback, requests, comments, tasks, attachments | Resident request, feedback form, repair tests | `/operations/resident-interactions` |
| Dịch vụ/phương tiện | Mutate, apartment vehicles, meter image | Services, assignments, vehicles, readings | Vehicle và meter image tests | `/operations/services-vehicles` |
| Tài chính | Financial workflow và imports | Bills, lines, receipts, allocations, adjustments, books | Financial, adjustment và receipt tests | `/operations/debt-payments` |
| Reports | Server page report builders và export | Financial/interaction aggregate sources | Debt, excess, finance report và export tests | `/operations/reports-ledgers` |
| RBAC | Auth, RBAC route và employee guards | Auth/user/group/assignment/audit models | Auth, CRUD permission và RBAC PostgreSQL tests | `/operations/accounts-permissions` |
| Import/export | Import và export handlers | Import records và target tables | Import/export tests | `/engineering/import-export` |
| Reminder | Queue, dispatcher và webhook | Campaign, notification, event, suppression | Reminder và webhook tests | `/engineering/integrations` |

Supporting test file tồn tại không chứng minh toàn bộ row; đây là trace target, không phải coverage percentage.
