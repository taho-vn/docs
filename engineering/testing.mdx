Source snapshot có 62 test files. `yarn test` generate Prisma Client rồi chạy `tsx --test --test-concurrency=1`. `yarn test:coverage` thêm Node experimental coverage với line threshold 80.

`yarn test:e2e` build application rồi chạy `scripts/e2e-smoke.ts`. `yarn verify` chạy unit/integration tests và E2E command theo `package.json` hiện tại.

## Kiểm thử một use case

<Steps>
  <Step title="Chọn use case">
    Mở [Use case và workflow](/product-specs/workflow-specifications). Dùng bảng traceability để tìm rule, state, route, persistence và test liên quan.
  </Step>
  <Step title="Đọc các nhánh">
    Kiểm tra success path, rejection path và stopping point trên flowchart. Không thêm nhánh mà source không thực thi.
  </Step>
  <Step title="Đối chiếu Acceptance Criteria">
    Mỗi `Given` phải là trạng thái đầu vào được code kiểm tra. Mỗi `When` phải là action thật. Mỗi `Then` phải là kết quả quan sát được hoặc persistence/side effect đã trace.
  </Step>
  <Step title="Chạy test hiện có">
    Chạy `yarn test`. Dùng test file trong bảng truy vết để hỗ trợ xác minh; test không thay thế việc đọc handler và service.
  </Step>
</Steps>
